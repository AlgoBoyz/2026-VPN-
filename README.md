## 机场推荐清单

### Nexitally

2017 年做到现在的老牌，自研面板，唯云专线。月付 ¥71 起，200G 流量，Shadowsocks / Trojan 协议，节点覆盖香港、日本、新加坡、台湾、美国。

价格在同行里偏高，但品质是它活到现在的原因。自研面板意味着客户端、订阅、节点切换都是自己控制，出问题响应快。适合预算充足、不想折腾的主力用户。

评价：机场界的老牌劲旅，专线和面板是核心竞争力，价格高但品质对得起。

### BoostNet

IEPL 专线 + AnyTLS 新兴协议的组合。月付 ¥39 起，200G 流量，AnyTLS 协议。

AnyTLS 是近两年冒出来的新协议，抗封锁能力比传统协议强，代价是客户端有门槛——需要 Clash Meta 内核或较新版本的客户端支持。偏高端 IEPL 机场，优惠码 `boost` 享 8 折。

评价：技术上有门槛，但抗封锁能力是实打实的，适合愿意折腾配置的用户。

### WgetCloud

2026 年稳定机场的首选之一。月付 ¥79 起，160G 流量，Trojan 协议。

特点是亚马逊加速线路，晚高峰体验有保障。价格偏高，定位专业用户，新用户 85 折。

评价：高端稳定之选，晚高峰表现扎实，适合对稳定性敏感的用户。

### Kuromis

唯云专线，跟 Nexitally 同上游。月付 ¥40 起，50G 流量，Shadowsocks / Trojan 协议。

同一条上游线路，价格比 Nexitally 低一截，适合想体验高端线路、预算又够不到 Nexitally 的用户。节点覆盖和 Nexitally 基本一致。

评价：Nexitally 的同门师弟，线路品质一致但门槛更低。

### OKANC

BGP 入口 + IEPL 专线，出道即巅峰。月付 ¥46 起，328G 流量，Shadowsocks 协议。

BGP 入口让不同运营商都能找到合适路径，IEPL 专线保证跨境段质量。提供免费试用，买之前可以先试再掏钱。适合预算充足、看重流媒体和商务稳定性的用户。

评价：BGP + IEPL 双保障，高端机场里性价比明显的一家。

### TAG

330+ 线路覆盖 100+ 国家，Shadowsocks 机场里的全球通。Silver 月付 ¥114，Special 年付 ¥162 起。

覆盖范围是它最大的卖点——除了常见的香港、日本、新加坡、台湾、美国，还有韩国、欧洲、南美、非洲、中东，甚至卫星网络。10 台设备同时在线是亮点。注意仅限大陆使用。

评价：全球覆盖最广的机场之一，低成本体验全球线路的好选择。

### AmyTelecom

佩奇系 AnyTLS 专线，流媒体解锁业界标杆。半年付 ¥196 起，50GB 月起，AnyTLS 协议。

传承了 Nexitally 的专线品质和流媒体解锁基因，价格比 Nexitally 月付 ¥74.55 有优势。注意 AnyTLS 协议需要 Clash Meta 等新客户端支持。

评价：流媒体用户的优选，解锁能力是招牌。

## 选购指南

选机场的门道比想象中多。以下内容来自 [airportrank.shop](https://airportrank.shop) 的长期实测整理，每篇都展开讲透。

### 专线和中转，多掏的那几十块花哪了

原文：[https://airportrank.shop/topics/xuangou-zhuanxian/](https://airportrank.shop/topics/xuangou-zhuanxian/)

白天用着顺畅的机场，一到晚上八点开始转圈，刷推特转半天，看视频卡成幻灯片。这种场景在机场用户里很常见，多数人以为是机场跑路了，其实只是线路不行。

机场出国就两种走法：中转和专线。两种走法的物理路径、成本结构、体验曲线完全不同，理解了这一点，很多机场圈的怪现象就都能解释。

### 中转：走公网，看命

中转的路径是：客户端先走公网跨境连到境外的中转服务器（通常是香港），中转机再转发到各落地节点。

公网是所有人共享的普通互联网通道。国内到海外的公网跨境带宽是有限的资源，晚高峰全民上网的时候，这条通道就是一条堵死的国道。中转机场的流量混在大军里，速度全凭运气：运气好赶上空窗期，速度可观；运气差赶上高峰期，测速直接腰斩再腰斩。

中转还有个隐藏问题：跨境公网线路本身存在拥塞和质量波动，运营商之间互联带宽不足是常态。白天测速正常，晚上高峰期掉速，不是机场偷工减料，是物理通道的固有属性。

中转的优势只有一条：便宜。服务器成本低，带宽按流量买，月付十块二十块的产品大多是这种。适合对价格敏感、对晚高峰体验要求不高的场景。

### 专线：走内网，稳定

专线的路径是：流量通过 IEPL 或 IPLC 专线跨过国境线。

IEPL（国际以太网专线）和 IPLC（国际私人租用电路）都是运营商之间的内网专线，不参与公网拥堵。相当于从国道换到一条只有付费用户在跑的高速，而且这条高速是固定预留带宽的——白天晚上一个样，高峰期不降速。

专线的物理属性决定了它的体验特征：延迟低且稳定，抖动小，带宽有保证。晚高峰该多快还多快，速度曲线基本是平的。打游戏、视频会议、4K 流媒体这些对稳定性和延迟敏感的场景，专线和中转的差距是肉眼可见的。

成本也摆在那：一条专线按月租计费，带宽越大越贵，还要搭上两端的接入设备。一条 IEPL 专线的月租够买十几台中转服务器，所以专线机场月付四五十起步，七八十也正常。专线的价格不是智商税，是成本决定的。

### 中转和专线的变体

市面上还有不少"半专线"产品，值得说清楚。

有的机场宣称"专线接入"，但只是跨境段的一部分走专线或精品线路，其余段落还是公网——这叫半程专线，效果比纯中转好，但高峰期没走专线的那段还是会卡。有的机场说"CN2 GIA"，这是电信的国际精品网，质量接近专线但本质还是公网产品，高峰期表现比普通公网好很多，但和真 IEPL 还是差一截。

判断一个机场是不是真专线，最简单的办法是看晚高峰测速：真专线晚上和白天差距很小，半专线和精品网会有明显掉速。还有看价格——真专线的成本结构决定了它便宜不了，月付 20 以内基本不可能是全专线。

### 什么时候中转够用

不是所有场景都需要专线。只刷推特看新闻、偶尔看视频的轻度使用，中转完全够用——高峰掉点速，刷个文字资讯毫无感知。

学生党预算有限，中转更合适。省下的钱可以同时备两三家，哪家挂了换哪家，反正成本低。当作备用的机场，更没必要上专线，便宜才是第一诉求。

轻度流媒体用户（看看 1080P，偶尔 4K）用中转也勉强能撑，高峰期会偶尔缓冲，但能接受。

### 什么时候专线省不得

有几类场景，专线的钱省不得：

每天开视频会议的场景。会议是实时双向流，晚高峰卡顿直接导致画面冻结、声音断续，一场会开得支离破碎。对打工人来说，会议体验的损失远超几十块月费。

跨境电商和外贸业务。这类用户把机场当生产工具，关键时刻掉链子损失的是订单和客户信任，不是月费能衡量的。专线带来的稳定连接，本质是业务保障。

网络游戏场景。游戏对延迟和抖动极其敏感，中转的晚高峰抖动直接表现为瞬移、丢包、掉线。专线的低抖动特性对游戏玩家是刚需。

重度流媒体用户。4K 视频需要稳定的大带宽，中转高峰期喂不饱，画面在 1080P 和 4K 之间反复横跳，体验很糟。专线能稳定跑满带宽，保证 4K 不掉帧。

### 判断标准

判断标准很简单：晚九点的高峰时段，如果当前的机场在开会、游戏、4K 视频等场景下出现明显卡顿，就该考虑换专线；如果这些场景下体验尚可，说明现有线路够用，没必要多花钱。

换个说法：专线贵的那几十块，本质是买晚高峰的稳定。白天测速再快，晚高峰拉了胯，对上述场景来说都是白搭。反过来，如果永远在白天用、对高峰无感，那专线的溢价确实没必要付。

线路这东西，没有"最好的"，只有"匹配需求的"。把使用场景列出来，对号入座，钱就花不冤枉。

### 机场卖 20 和卖 80，到底差在哪

原文：[https://airportrank.shop/topics/xuangou-jiage/](https://airportrank.shop/topics/xuangou-jiage/)

机场行业的价格从月付几块钱到上百块钱不等，差价主要落在四样东西上：线路、协议与面板、IP 池、运营年限。这四样决定了不同价位机场的本质区别，也决定了晚高峰的体验差距。

### 线路：差价的最大头

最贵的是线路。便宜的机场走中转架构：中转服务器部署在境外（通常是香港），客户端先走公网跨境连到中转机，再由中转机转发到各落地节点。公网跨境段的带宽是有限的，晚高峰八点到十一点，全国用户一起用，拥堵程度全看运气。中转机场的典型表现是白天正常、晚上掉速，高峰期测速只有白天的三分之一甚至更低。

贵的机场走 IEPL 或 IPLC 专线。这类专线的跨境段走运营商内网，不参与公网拥堵，物理带宽是固定预留的。晚高峰该多快还多快，速度曲线基本是一条直线。这就是为什么同样看 4K，专线机场高峰不掉帧，中转机场转圈——不是服务器快慢的问题，是走的通道根本不同。

一条专线的成本相当可观：IEPL 专线按月租计费，带宽越大单价越高，一条 100M 的 IEPL 月租能抵十几台中转服务器的全部开销。所以专线机场的定价下限天然就高，四五十起步是常态，七八十也不稀奇。中转机场十块二十块能卖，是因为服务器便宜、带宽按流量买，成本结构完全不同。

专线买的是稳定，中转买的是便宜。天天开会打视频的场景，专线的钱省不得；只是睡前刷两个小时的场景，买专线属于浪费。

### 协议与面板：第二块成本

市面上大部分机场用开源面板套壳开张，SSpanel、V2board 改个皮就上架。这类机场与其他几十家共用同一套技术栈，好处是成本低、开张快，坏处是协议一旦被批量识别，大家一起遭殃——GFW 封锁从来不是针对某一家的，是按协议特征一锅端。

价格更高的机场往往自研面板和协议。自研意味着协议特征不公开，封禁的响应速度更快，别人被墙了自己还能用。例如部分机场实现了 MPTCP 隧道——一条线路被限速时另一条顶上，连接不断流；还有些机场用 AnyTLS、Reality 这类新协议做流量伪装，把代理流量伪装成普通 HTTPS 访问，特征库很难识别。

自研投入的具体价值难以量化，但至少说明团队有技术储备。愿意在协议层持续投入的团队，通常也愿意维护线路和服务器——这两件事是同一个成本结构。跑路概率明显更低，不是玄学，是投入沉没成本决定的。

### IP 池：解锁能力的根基

IP 池决定流媒体解锁的上限。解锁 Netflix 原画需要干净的真实 IP——所谓"干净"，是指没有被流媒体平台标记为代理出口的 IP。

自有 IP 数量多的机场，单个 IP 被封后立即切换，解锁长期稳定。这类机场通常持有上千个 IP，分布在多个地区，被流媒体平台封掉一批还有替补。租用共享 IP 的机场，一个 IP 被几十上百个用户共用，很容易触发平台的风控，今天能看明天不能看，属于开盲盒。

判断一个机场的 IP 实力，可以看它敢不敢承诺"原生解锁"。原生解锁靠真实 IP 直接访问，稳定；DNS 劫持式的伪解锁，表面能看，实际走的是代理转发，画质和稳定性都差一截，还会被平台逐步封杀。

### 运营年限：最容易被忽视的成本

运营年限是最后一块。机场行业的跑路率极高，一家从 2017 年运营至今的机场与一家上个月开张的机场，跑路风险不在一个量级。

老牌机场的价值在于积累：线路资源是长期租约，IP 是逐年沉淀的，用户口碑是时间堆出来的。这些东西都没法速成，所以老牌机场的定价里天然包含"信任溢价"。这笔钱花得值不值？从跑路概率看，值。

反过来，新机场也不是不能买——很多新机场为了抢用户，前几个月价格极低、服务极好。问题在于无法判断它是"有野心的新玩家"还是"捞快钱的临时工"。稳妥的做法是让子弹飞一会儿：新机场先月付观察，跑路前兆出现立刻撤。

### 价位分层：钱花在哪一档

月付 30 元以内的产品，适合当工具使用。这个价位的核心诉求是"能用"，坏了就换，不需要投入感情。这类机场大多是中转线路，晚高峰会卡，但轻度使用场景下够用。

30 到 80 元的产品开始讲究体验。值得关注专线比例、解锁能力和设备数量。这个区间竞争最激烈，也是产品差异最大的区间——有的把钱花在线路上，有的花在 IP 上，有的花在设备数上，按自己的需求挑。

80 元以上的产品，购买的已经不是翻墙能力本身，而是稳定性和省心。这个价位的机场通常专线起步、IP 池深厚、技术团队完备，适合把机场当生产力工具的用户。价格再往上，边际收益递减明显，更多的是品牌溢价。

### 无论哪个价位：先月付

无论选择哪个价位，第一个月都应该按月付。用满一个月确认值得，再考虑年付。

一上来就年付，等于拿钱赌运营方的良心。机场行业跑路太常见，年付省下的那点折扣，抵不上跑路损失的风险。哪怕是最老牌的机场，也建议至少先用一个月月付——不是不信任，是习惯问题，把主动权握在自己手里。

### 买机场之前，先想清楚自己是哪类用户

原文：[https://airportrank.shop/topics/xuangou-leixing/](https://airportrank.shop/topics/xuangou-leixing/)

很多人买机场是跟风：看到一篇推荐文章写得天花乱坠，价格也合适，就下单了。三个月后机场一次没打开过——打开过两次，都是为了找回密码。需求没想清楚就上车，是机场消费最常见的浪费。

按使用场景，机场用户大致分五类。每类用户的核心诉求、该买的配置、该避开的坑都不一样。

### 第一类：轻度冲浪党

每天刷半小时 Twitter、看两眼 YouTube、偶尔查个资料。这类用户流量用得少，但怕折腾。

核心诉求是"省心"。流量多少无所谓，50 到 200G 月流量顶天，重点不是速度而是客户端好不好配置——为配 Clash 折腾一下午对这类用户是灾难。他们需要的是打开就能用的产品，最好连订阅链接都不用自己填。

这类用户容易踩的坑是买大流量套餐。500G、1000G 看着划算，实际用不完，纯属浪费。Team 版、企业版更是毫无必要。另外一个常见误区是追求极限速度——轻度使用场景下，50M 和 500M 的体验差异几乎感知不到，为用不上的速度付费不划算。

适合的产品特征是：客户端配置简单、订阅稳定、月付便宜。线路是专线还是中转，对这类用户的影响很小。

### 第二类：视频重度党

晚上不看两集剧睡不着，4K 是底线，Netflix、Disney+ 常驻。这类用户是流量大户，对解锁能力要求极高。

核心诉求有两个：流量足、解锁全。500G 以上起步，流媒体解锁必须全——Netflix、Disney+、YouTube 一个不能少。解锁能力是硬指标，不是锦上添花：流媒体平台对代理 IP 的封禁很积极，解锁不稳的机场，今天能看明天被封，体验极差。

这类用户最容易踩的坑是贪便宜买"不保证解锁"的产品。标注不保证解锁的，基本就是解锁能力不行。白天能用晚上被封，反复折腾，最后算总账比直接买贵的还亏。另一个坑是不看 IP 池——原生 IP 解锁比 DNS 劫持稳太多，IP 池大的机场，封一个换一个，长期稳定。

适合的产品特征是：大流量档位、解锁能力强、IP 池深厚。优先选专线机场——4K 流媒体对带宽要求高，中转高峰期喂不饱，4K 和 1080P 之间反复横跳很折磨人。

### 第三类：多设备家庭用户

手机、平板、笔记本、电视盒子、爸妈的 iPad 全家一起用。这类用户设备多，需求不是一个人能用，而是全家同时能用。

核心诉求是设备数。设备数比流量更敏感，要选设备数 5 台以上的档位，最好 10 台。限制 2-3 台的个人版永远有一台设备挤不下来——不是流量不够，是同时在线名额不够。

这类用户容易踩的坑是不看"同时在线"限制。很多机场写着 5 台其实是 5 台轮流用——同一时间只能一台在线，另一个设备连上就把前面的挤掉。家里几个人同时用的时候，这种限制就是灾难。买之前务必确认是"同时在线"还是"轮流使用"，这个差别很大。

另一个坑是买多份个人版代替家庭版。三份个人版的价格往往比一份家庭版贵，管理还麻烦，不如直接上一份设备数足够的套餐。

### 第四类：全球出差党

人在非洲，飞机落中东，下周去南美。这类用户的特征是移动性强、网络环境差、需求变化快。

核心诉求是覆盖范围。线路覆盖 50+ 国家以上是底线，最好有卫星网络节点——卫星节点意味着即使在地面网络覆盖不到的偏远地区也能连接。只有美日港韩四件套的产品，到了偏远地区直接失联。

这类用户容易踩的坑有两个。一个是只看速度不看覆盖：测速快的是美日港，真到了需要的地方没节点，等于白买。另一个是买只限大陆使用的产品——很多机场的服务范围严格限制在大陆，人在海外连接会被拒，买了才发现翻不回来。买之前一定要确认服务范围。

适合的产品特征是：节点覆盖广、支持地区多、有备用域名。全球出差党的机场是"保命工具"，稳定性比速度重要得多。

### 第五类：生产力用户

远程办公、跨境电商、开发者，机场是吃饭的家伙。这类用户对机场的依赖是刚性的，不是娱乐需求。

核心诉求是稳定性和可预期性。专线起步，老牌优先。新开的、价格低得离谱的机场不能碰——拿吃饭的家伙赌跑路概率，不值。看运营年限，2017 年活到现在的跟上个月开张的，风险完全两个量级。

这类用户容易踩的坑是把工作和娱乐混用一个机场。工作流量和娱乐流量混在一起，一旦娱乐节点被墙或限速，工作也跟着遭殃。预算允许的话，工作用一个稳定的专线机场，娱乐用便宜的，互不干扰。

另一个坑是忽略设备数限制。生产力用户往往电脑手机多台设备同时在线，个人版的 2-3 台限制很快就不够用，买之前算好同时在线需求。

### 对号入座

对应关系大致如下：轻度冲浪月付 10-30 元足够，视频重度 40-80 元，多设备家庭 30-70 元，全球出差 50-100 元，生产力用户 70 元起步。

这个价格区间是参考，不是铁律。核心逻辑是：需求决定配置，配置决定价格。想清楚自己是哪类用户，预算范围内的选择就那几个，闭眼挑都行。

机场不是越贵越好，也不是越便宜越赚。需求想明白了，钱就花得值。怕的就是跟风——别人说好就买，买完吃灰，还怪机场不行。

### 机场防跑路手册：年付之前先想清楚

原文：[https://airportrank.shop/topics/xuangou-bikeng/](https://airportrank.shop/topics/xuangou-bikeng/)

机场行业的跑路率在互联网服务里属于最高的一档。今天还在搞周年庆大促，明天官网打不开，群解散，客服已读不回——年付的钱就这么蒸发了。

跑路不是随机事件，几乎每次都有迹可循。识别前兆，是止损的第一步。

### 跑路前的四个前兆

**一是突然大促、力度反常。**"原价 199 年付，现价 99，最后三天"——正常促销没问题，但价格低到不像话的，多半是准备收割最后一波。判断标准很简单：卖得越狠，跑得越快。正常运营的机场靠口碑慢慢积累用户，跑路前的机场只想在短时间内把能收割的钱收割完。如果一个大促同时叠加"新用户特惠""老用户续费半价""推荐返利翻倍"，基本就是在做最后的冲刺。

**二是客服集体消失。** 以前秒回的 TG 客服，现在半天不回、一天不回。不是忙，是在打包行李。正常的机场客服就算忙，也会挂个自动回复或者发个公告说"处理中"；跑路前的机场，客服开始装死，问套餐问节点都含糊其辞，甚至直接解散用户群。客服的态度变化，往往比官网公告更早暴露真相。

**三是官网频繁换域名。** 偶尔换一次正常（被墙了），但三个月换三次，每次还都是新域名——这是在为跑路后不留把柄做准备。被墙换域名是主动求生，跑路前换域名是被动清场。区别在于：前者换完域名一切照旧，后者换完域名开始失联。

**四是停止更新。** 公告不发了、节点不加了、测速图不更新了。运营停滞的机场，离跑路就差一个清空数据库的操作。正常机场哪怕再懒，也会定期加节点、发公告、更新状态页；跑路前的机场，连维护用户信任的成本都不愿意花了。

前兆出现两个以上，就该准备后路。不要心存侥幸——跑路机场的用户群里，最后悔的都是"我早发现不对，但还是续费了"的人。

### 年付是最大的坑

年付是机场行业最大的坑。运营方收了一年的钱，服务器成本是按月付的，钱躺在账上，跑路的诱惑太大。

月付最多损失一个月，当交学费；年付一旦跑路，钱全打水漂，还没处说理。这不是概率问题，是风险敞口问题——月付的风险敞口是几十块，年付的风险敞口是几百上千块，一旦跑路，损失差一个量级。

铁律是先月付三个月，觉得稳了再谈年付。有些老牌机场年付折扣确实香（能省 20-30%），但那是给用了一年以上的老用户的，不是给新人的。老用户对机场有完整的体验样本，知道它稳不稳；新用户拿什么判断？就凭官网几张截图？

还有一种更隐蔽的年付陷阱：先放出低价年付套餐，收钱后服务质量断崖下跌——线路缩水、带宽减半、客服消失。钱已经收了，投诉无门，只能吃哑巴亏。所以年付前除了看口碑，还要看这家机场对老用户的态度：老用户续费有没有优惠、有没有稳定运营的历史记录。

### 封号雷区：自己作没的号

有些号不是机场跑路，是自己作没的。封号原因大多是这几类：

**分享订阅链接。** 几乎全部机场禁止。发到群里别人一用，号直接冻结。机场的逻辑很简单：订阅链接是账号凭证，分享等于把账号给陌生人用，风控系统按异常登录处理。有些人觉得"我就发给自己小号"，但系统不知道，只看登录设备数和地域特征。

**短时间大量设备登录。** 脚本党、把机场当 CDN 用，封号没商量。一个账号正常使用是几台设备，突然变成几十台设备同时在线，流量特征异常，风控直接触发。有些机场限制同时在线设备数，超了不是挤掉旧设备，而是直接封号。

**流量异常。** 一个月用掉正常人十倍的量，风控系统不封才怪。正常用户一个月几十到几百 G，突然跑出几个 T，不是脚本就是多人共用，封号合理。

**恶意退款。** 用一周退款，退了再买再退，直接拉黑名单。支付平台的退款记录机场后台看得一清二楚，反复退款的账号会被标记，轻则拉黑，重则连累支付渠道。

规矩就一条：买前读规则，买后别作妖。机场的规则页面都写得明明白白，大部分封号都是没读规则造成的。

### 跑路之后的止损顺序

真碰上跑路，按顺序操作：

**立刻停止续费。** 别让损失扩大。如果用的是支付宝/微信自动续费，马上关掉；绑定了 PayPal 的，取消授权。

**导出订阅链接和节点信息。** 万一还能抢救一下。有些机场跑路前会短暂恢复，抢在窗口期把配置导出来，至少节点信息还在手里。

**去 TG 搜机场名。** 跑路机场一般有受害者群，里面会有人整理替代方案、整理维权信息，甚至会有其他机场来"接盘"发优惠。信息比一个人瞎找强。

**换一家。** 这行最不缺新机场，别跟一家死磕。重点是从这次跑路里总结经验，下次选机场多留个心眼。

**把教训记下来。** 哪家跑路、什么前兆、损失多少，记下来。下次看到类似的机场特征，直接绕开。

### 不容易跑路的机场长什么样

不容易跑路的机场有几个共同点：

**运营年限长。** 2017 年活到现在的跑路概率低一个量级。时间是最好的筛选器，能穿越几轮封锁周期的，说明技术、资金、运营都撑得住。

**技术投入实。** 自研面板、自研协议、自有 IP 池的跑路成本高——这些东西是真金白银砸进去的，说跑就跑，沉没成本太大。对比之下，套壳机场开张成本几乎为零，跑路毫无心理负担。

**有库存机制。** 敢限售（"售罄就没了"）说明在控制带宽，不是捞快钱。无限超卖的机场，要么不懂运营，要么根本没打算长期做。

**口碑干净。** 多搜"XX 机场 跑路"，搜不到黑历史的才敢碰。机场圈的传播速度极快，跑路过一次的机场，搜出来全是黑料；没跑路过的不一定稳，但跑路过的一定不稳。

### 最后

机场跑路本质上是在赌运营方的良心。能控制的部分只有：月付、选老牌、看前兆、留后路。

做到这四条，就算真跑路了，损失也不过是一杯奶茶钱。跑路是行业常态，但跑路坑到的永远是那些把全部赌注押在年付上的人——别做那个人。

### 机场协议科普：SS、VLESS、Reality、AnyTLS 都是什么

原文：[https://airportrank.shop/topics/xuangou-xieyi/](https://airportrank.shop/topics/xuangou-xieyi/)

机场详情页和套餐说明里，总有一行写着"支持协议：SS、VLESS、Reality……"。这些缩写对老用户是常识，对新用户就是天书。其实协议没那么玄，核心就一个事：客户端和服务器之间用什么暗号对上暗号、怎么把流量藏起来过墙。

### 协议在机场里的角色

机场的本质，是提供一批境外服务器节点，客户端连上这些节点，把流量代理出去。协议就是客户端与节点之间约定的通信格式——怎么握手、怎么加密、怎么伪装。协议选得好不好，直接决定流量被 GFW 识别的难度，也就是"抗封锁能力"。

协议不是机场自己发明的，都是开源社区的产物。机场做的只是部署、维护、挑一个适合自己线路的协议。所以协议的新旧和优劣，基本可以反映机场的技术水平——只用老协议的机场，要么懒，要么没能力。

### 第一代：Shadowsocks（SS）

Shadowsocks 是最经典的协议，2012 年诞生，至今还在大量使用。原理是把流量加密后通过一个看似普通的 TCP 连接传输，早期对抗 GFW 效果很好，因为流量特征不明显。

但十几年过去，GFW 对 SS 的特征识别已经相当成熟。现在纯 SS 协议在高峰期容易被探测和干扰，速度不稳、连接被重置是常事。机场里还保留 SS 节点，通常是兼容老客户端，或者作为备用线路。老牌机场的 Shadowsocks 节点质量普遍还行，新机场还在主推 SS 的，多半是技术栈老旧。

### 第二代：VMess 和 VLESS

VMess 是 V2Ray 项目推出的协议，比 SS 多了一层元数据加密，抗识别能力更强。当年 V2Ray 火起来，靠的就是 VMess。后来社区发现 VMess 的元数据格式有特征可循，又推出了 VLESS——更轻量、去掉冗余元数据，配合 TLS 伪装使用。

VLESS 本身不加密，必须配合 TLS（即 HTTPS 那层加密）才能安全传输，所以机场里的 VLESS 节点几乎都是"VLESS + TLS + WS"的组合，伪装成网页访问。这套组合是目前机场的主流配置，成熟、稳定、客户端支持广，Clash、v2rayN、Shadowrocket 全都兼容。

### 第三代：Trojan 和 Reality

Trojan 的思路更直接：流量长得跟标准 HTTPS 一模一样，连 TLS 握手都是真的，只是把代理数据藏在里面。GFW 想识别 Trojan，就得先判断这条连接是不是真实的网页访问——这基本做不到。Trojan 一度是最难被封的协议，代价是部署时需要一个真实的域名和证书。

Reality 是 2023 年之后的新锐，VLESS 家族的后继者。它更进一步：不需要自己的域名和证书，直接借用其他网站的 TLS 指纹，连握手特征都伪装成访问那个网站。换句话说，流量看起来就像在访问一个正常的大网站，GFW 很难有理由拦截。Reality 目前是抗封锁能力第一梯队的协议，新机场、高端机场基本都标配。

### 第四代：AnyTLS 和 Hysteria2

AnyTLS 是最近两年冒出来的，核心卖点是流量伪装成普通 TLS 连接，特征库难以识别，同时对高延迟、丢包环境的适应性做了优化。它的问题是客户端支持还不多——Clash Meta 和 Surge 支持，部分客户端还在跟进。选 AnyTLS 的机场，通常是技术驱动型团队，值得高看一眼。

Hysteria2 走的是另一条路：基于 UDP，用 QUIC 协议传输，专为高丢包、高延迟的网络环境设计。在丢包严重的线路上，Hysteria2 的表现比 TCP 系协议好很多，弱网下速度优势明显。代价是 UDP 流量在某些网络环境下会被 QoS，而且对网络环境挑剔。

### 怎么看待协议的宣传

机场宣传协议，要看两点。

一看是不是主流。VLESS + Reality、VLESS + TLS、Trojan、AnyTLS，这些是当前的主流，抗封锁能力和客户端兼容性都有保障。如果机场主推的还是纯 SS 或者老版 VMess，说明技术栈没跟上，抗封锁能力存疑。

二看协议是否匹配线路。协议只是传输层的事，线路才是体验的大头——再新的协议走公网中转，晚高峰一样卡。Reality 配专线是顶配，SS 配专线也比 Reality 配中转强。协议管的是能不能过墙，线路管的是过墙后快不快，两者的分量不在一个量级。

### 机场线路术语：入口、落地、中转、CN2、BGP 都是啥

原文：[https://airportrank.shop/topics/xuangou-xianlu/](https://airportrank.shop/topics/xuangou-xianlu/)

机场的线路描述是玄学重灾区。"CN2 GIA 三网直连""BGP 多线接入""IEPL 专线落地"——每个词都认识，连起来不知道在说什么。其实线路术语就那么几个核心概念，拆开讲不难。

### 入口和落地

机场的流量路径分两段：国内这一段叫入口，境外那一段叫落地。

入口是客户端连上去的第一跳，通常部署在国内或香港等靠近大陆的位置，负责接收用户流量、转发到境外。入口的质量决定连接稳不稳定——入口离用户近、线路好，握手就快，不容易断。

落地是流量最终出去的节点，也就是目标网站看到的出口 IP 所在位置。落地决定 IP 归属地和解锁能力：看 Netflix 美区，需要美国落地 IP；看 ChatGPT，需要干净且支持地区的 IP。落地服务器的带宽和质量，决定实际下载速度。

一个机场的节点描述，基本就是"入口 + 落地"的组合：入口负责接入，落地负责出口。两者都强，体验才好。

### 中转和直连

直连是客户端直接连到境外节点，中间没有转发服务器。节点如果离大陆近（香港、台湾、日本），直连延迟低；离得远（美国、欧洲），直连的跨境公网路径长，路由绕、丢包多，晚高峰容易卡。

中转是加了一台境外（通常是香港）的转发服务器：客户端走公网跨境连到中转机，中转机再转发到落地节点。中转的核心优势是跨境线路优化——中转机部署在香港这类跨境线路质量好的位置，可以接入 CN2、CMI 这类优化线路，把客户端到落地之间那段又长又绕的跨境公网，拆成"客户端到中转机 + 中转机到落地"两段，每段都走可控的好线路。代价是多一跳，延迟会比直连多一些，但换来的是跨境段质量有保障，丢包、抖动、晚高峰表现都比直连可控。直连看似少一跳，跨境公网的路径却固定没得挑，绕路、丢包、晚高峰卡顿全看运气。

判断一个节点是中转还是直连，看延迟和路由就行：中转节点通常延迟稳定、路由清晰；直连远距离节点延迟高、晚高峰波动大。

### 专线和精品网

专线（IEPL/IPLC）是运营商之间的内网专线，跨境段不参与公网拥堵，晚高峰不掉速。这是机场线路里最贵的部分，也是高端机场的核心卖点。

精品网是公网线路里的"高级车道"，最知名的是电信的 CN2 GIA。CN2 是电信的国际精品骨干网，GIA 是其中质量最好的产品线，三网（电信、联通、移动）都能走 CN2 出口，高峰期表现远超普通公网。但 CN2 GIA 本质还是公网，不是专线，晚高峰会掉速，只是比普通公网掉得少。

还有一种半专线：跨境段的一部分走专线或精品线路，其余段落走公网。效果比纯中转好，但没走专线的那段高峰期还是会卡。宣传只说"专线接入"不说是全段还是半段的，大概率是半程。

### BGP 和 IXP

BGP 是互联网的"路由协议"，全称边界网关协议，负责告诉各网络"去某个 IP 该走哪条路"。机场说自己"BGP 多线接入"，意思是服务器接入了多家运营商网络，理论上可以选择最优路径——电信用户走电信线路，联通用户走联通线路，各走各的，互不拖累。但宣传归宣传，实际优化效果参差：接了几家上游不代表优化得好，路由策略怎么配、和国际网络的互联质量如何，才是真正决定体验的部分。很多号称"BGP 多线"的机场，实际三网表现也就那样，这条得靠实测验证，不能看宣传下结论。

IXP 是互联网交换中心，各运营商和内容商的网络在这里互联互通。接入 IXP 多的机房，和国际网络的互联选择更多。但"接没接"和"优化好不好"是两码事——接入 IXP 只是拿到了互联的资格，实际走不走、走得顺不顺，取决于路由策略。同样一句"接入 XX IXP"，有的机房互联质量极高，有的就是挂个名头，效果差得远。这类宣传看看就好，判断标准还是实测：晚高峰、跨运营商、跨国线路各测一遍，比什么宣传都有说服力。

### 怎么读一条节点描述

拿一条典型的节点描述举例："香港 IEPL 专线，BGP 多线接入，落地原生 IP"。拆开看：IEPL 专线说明跨境段是内网专线，晚高峰稳；BGP 多线说明网络配置有底子，但实际三网表现还得实测确认；原生 IP 说明解锁能力强。这条节点配置上是高端路线，实际体验取决于落地和路由策略的落实情况。

反过来，"美国中转，普通线路"——说明跨境段走公网，晚高峰会卡，但便宜。这类节点适合不追求高峰体验的用户。

说到底，线路术语描述的就是这条流量路径上每一段花了多少钱：专线贵在跨境段，BGP 贵在入口段，原生 IP 贵在出口段。看懂每一段，机场的定价良心不良心，心里自然有数。

### 流媒体解锁术语：原生 IP、DNS 劫持、解锁失效都是啥

原文：[https://airportrank.shop/topics/xuangou-jiesuo/](https://airportrank.shop/topics/xuangou-jiesuo/)

机场圈有个高频词：解锁。解锁 Netflix、解锁 Disney+、解锁 ChatGPT——听起来像破解，其实不是。流媒体平台的"解锁"指的是：让平台认为访问者来自它支持的地区，从而放行内容。

这背后是一套完整的 IP 识别体系，机场在这套体系里的表现，直接决定解锁稳不稳。

### 平台怎么判断访问者地区

Netflix、Disney+、ChatGPT 这类平台，判断用户地区主要看出口 IP 的归属地。IP 是互联网的地址，每个 IP 都对应一个注册地区。平台查一下 IP 归属，就知道用户"在哪"，然后决定放行哪个地区的内容。

问题在于，代理机场的出口 IP 很容易被识别为"代理地址"。平台维护着一份庞大的代理 IP 黑名单，凡是数据中心、机场常用的 IP 段，都在重点监控名单里。出口 IP 一旦被标记，平台就会拒绝访问，或者只给最低清晰度——这就是"解锁失效"。

### 原生 IP：解锁的基础

原生 IP 指的是由当地运营商直接分配的 IP，而不是数据中心或云厂商的 IP。比如一个美国原生 IP，是由美国某家运营商（Comcast、AT&T 这类）分配的，IP 归属数据库里显示的是普通家庭宽带用户，而不是机房。

平台对原生 IP 的信任度最高，因为看起来就是普通用户在访问。机场宣称"原生解锁"，意思是它持有一定数量的原生 IP 池，出口流量通过这些 IP 走，平台识别不出代理特征。

原生 IP 的价值在稀缺性：运营商分配的原生 IP 数量有限，价格比普通机房 IP 贵很多。机场的原生 IP 池越大，解锁越稳定——被封掉一批还有替补。

### DNS 劫持：伪解锁的真相

有些机场宣称"全解锁"，但用的是 DNS 劫持方案。原理是：平台判断地区时，除了看 IP，还会查域名的 DNS 解析结果。机场在 DNS 层面把平台的域名解析到指定地区的服务器，让平台"以为"用户在该地区。

DNS 劫持的解锁是假的——它只骗过了地区判断，但流量最终还是从机场出口走的，IP 特征一查就露馅。表现是：能打开、能看列表，但实际播放时画质受限、频繁报错，或者一段时间后直接被封。这就是为什么有些便宜机场"解锁"时好时坏。

区分原生解锁和 DNS 劫持，最简单的办法是看 IP 归属：用查询工具查一下机场出口 IP 的归属地，如果显示是普通运营商，大概率是原生；如果显示是数据中心，那就是伪解锁。

### 为什么解锁会失效

解锁失效是机场用户最常遇到的怪问题之一：昨天还能看 Netflix，今天突然"此地区不可用"。原因大多是这几个：

IP 被封。出口 IP 被平台拉黑，这种情况在共享 IP 上最常见——一个 IP 被大量用户使用，触发风控，整个 IP 段被封。

IP 池用完。机场的原生 IP 数量有限，封一个少一个，池子见底就只能用普通机房 IP顶着，解锁自然失效。

平台风控升级。Netflix、ChatGPT 这类平台的反代理策略一直在更新，识别算法越来越强，昨天还安全的 IP 今天可能就被标记。

机场偷工减料。宣传时说解锁，实际用的就是普通 IP 加 DNS 劫持，风控一升级就原形毕露。

### 怎么判断机场的解锁实力

看宣传没用，看实锤。几个判断维度：

看 IP 池规模。机场如果敢公布自有 IP 数量（比如"2000+ 自有 IP"），说明解锁是有根基的；只含糊说"全解锁"不透露 IP 情况的，存疑。

看解锁承诺范围。Netflix、Disney+、YouTube、ChatGPT 全解锁，和只承诺"部分平台可用"，含金量完全不同。注意看有没有"不保证"字样——写明了不保证的，基本就是解锁能力不行。

看历史口碑。解锁能力是动态的，搜一下机场名加"解锁"看用户反馈，被封过几次、恢复快不快，心里就有数了。

解锁本质上是一场 IP 可信度的博弈：原生 IP 是硬通货，DNS 劫持是障眼法，IP 池规模是底气。看机场的解锁能力，与其问"能不能解锁"，不如问"原生 IP 有多少、池子多大"——答案的质量，基本决定了解锁的质量。

### 机场使用术语：订阅、倍率、节点、晚高峰都是啥

原文：[https://airportrank.shop/topics/xuangou-shiyong/](https://airportrank.shop/topics/xuangou-shiyong/)

买好机场、导入客户端之后，使用过程中还会碰到一堆术语：订阅过期了、倍率 0.1 是什么意思、节点标红是啥情况、晚高峰为什么卡。这些词看着小，不懂就会在关键时刻掉链子。

### 订阅：机场的"账号凭证"

订阅（Subscription）是机场提供的一串链接，里面包含了账号信息和节点列表。客户端导入订阅链接后，就能自动获取所有节点、自动更新——机场加了新节点，客户端刷新一下就同步。

订阅链接的本质是个人凭证，泄露了别人就能用这个账号。所以机场普遍禁止分享订阅链接，发现异常登录直接封号。换设备、重装客户端，只要订阅链接还在，导入就能恢复。

订阅还有两个常见状态词：过期和失效。过期是套餐到期，续费即恢复；失效是链接被重置（比如机场怀疑泄露、或者用户手动重置了订阅），需要去面板重新获取。

### 节点倍率：流量怎么算的

节点倍率是机场计算流量消耗的系数，常见 0.1、1、2 这些数值。倍率 1 的节点，用 1GB 算 1GB；倍率 0.1 的节点，用 1GB 只算 0.1GB；倍率 2 的节点，用 1GB 算 2GB。

倍率低的节点通常是机场的"广告位"——希望用户多走这条线路，或者这条线路成本低。倍率高的节点通常是热门线路、高峰期资源紧张的线路，机场用倍率调节流量成本。

看套餐够不够用，不能只看流量数字，要看常用节点的倍率。如果主力节点倍率 2，200G 套餐实际可用量就是 100G。买套餐前看清楚节点倍率分布，能避免"流量怎么没得这么快"的困惑。

### 节点状态：绿、黄、红

客户端里节点名前面会有颜色标识：绿色是正常，黄色是拥堵或延迟高，红色是超时或不可用。颜色是客户端按最近一次测速和握手结果判定的，实时性有限——标绿的节点高峰期也可能卡，标红的节点过一会儿可能就恢复。

节点标红先别急着换机场，常见原因：本地网络波动、节点维护、被墙正在换 IP。等几分钟刷新再看；如果长期标红，说明这条节点有问题，去机场公告或群里看看是不是在维护。

### 晚高峰：机场体验的试金石

晚高峰指晚上八点到十一点，全国用户集中上网的时段。这个时段公网跨境线路拥堵，中转机场掉速明显，专线机场相对稳定。

晚高峰是检验机场成色的标准场景：白天测速都好看，晚高峰才是真功夫。买机场前，最好在晚高峰时段实测一下——白天测速再快，晚高峰拉了胯，等于白买。

### 同时在线和设备数

机场套餐都会标注设备数，比如"5 台设备""10 台设备"。设备数指的是账号允许同时登录的设备数量，不是"可以安装的客户端数量"。

要注意"同时在线"和"轮流使用"的区别：有的机场写着 5 台，但同一时间只允许 1 台在线，其他设备连上会把前面的挤掉；有的机场是真正的 5 台同时在线。家庭多设备用户买之前务必确认这一点，差之毫厘，体验谬以千里。

### 流量重置：周期怎么算

机场套餐的流量按月或按周期重置，常见两种算法：自然月重置（每月 1 号清零重算）和按购买日重置（从购买日起算 30 天）。两种算法下，月底买套餐的划算程度完全不同——自然月重置的话，月底买等于白亏半个月流量。

买套餐前看一眼流量重置规则，月底入手的用户尤其注意。有些机场支持"流量不清零"或"按比例折算"，这类政策友好的机场值得加分。

这些术语背后都是成本核算：倍率是流量成本，晚高峰是线路成本，设备数是并发成本，重置周期是时间成本。把每个词对应到成本上，买套餐、看节点、判断机场值不值，就都有了依据。
